# React

> Guía de estudio + ejercicios por niveles para dominar React desde cero.

React es la librería de UI más popular. Esta sección cubre desde JSX y componentes hasta hooks, estado global, formularios, peticiones y renderizado en servidor.

## Guías de estudio

| # | Guía | Qué cubre |
|---|---|---|
| 01 | [Fundamentos](01-fundamentos.md) | Qué es React, JSX, componentes funcionales, props, renderizado, Virtual DOM, create-react-app/vite |
| 02 | [Hooks y estado](02-hooks-y-estado.md) | useState, useEffect, useRef, useMemo, useCallback, useContext, useReducer, custom hooks, dependencias |
| 03 | [Rutas y estado global](03-rutas-y-estado-global.md) | React Router, rutas anidadas, useParams, useNavigate, Context API, Redux, Zustand, Jotai |
| 04 | [Formularios y peticiones](04-formularios-y-peticiones.md) | Formularios controlados, React Hook Form, Zod, fetch con React, SWR, React Query, TanStack Query |
| 05 | [Producción y SSR](05-produccion-y-ssr.md) | Next.js, SSR, SSG, ISR, Server Components, React 18 concurrent features, performance, testing |
