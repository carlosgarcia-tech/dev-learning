# 03 — Step controls

## Enunciado

Aprende los controles de ejecución del debugger.

## Requisitos

1. Crea `solucion/respuesta.txt` explicando la diferencia entre Step Over (F10) y Step Into (F11).

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Step Over (F10): ejecuta la línea actual sin entrar en funciones.
Step Into (F11): entra dentro de la función que se está llamando.
```

</details>
