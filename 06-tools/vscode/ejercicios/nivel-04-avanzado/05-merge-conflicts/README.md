# 05 — Merge conflicts

## Enunciado

Resuelve conflictos de merge con VS Code.

## Requisitos

1. Explica en `respuesta.txt` qué opciones ofrece VS Code al detectar un conflicto.
2. Menciona las 3 opciones principales.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
VS Code muestra botones encima del conflicto:
- Accept Current Change: quedarte con HEAD.
- Accept Incoming Change: quedarte con la versión entrante.
- Accept Both Changes: combinar ambas.
```

</details>
