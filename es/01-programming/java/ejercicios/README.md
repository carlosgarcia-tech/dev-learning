# Ejercicios — Java

30 ejercicios en 5 niveles de dificultad. Cada ejercicio tiene **enunciado, requisitos, pistas y solución** (plegable). Compila y ejecuta cada solución con:

```bash
javac Ejercicio.java
java Ejercicio
```
