# 04 — Atajos esenciales

## Enunciado

Aprende los atajos más útiles.

## Requisitos

1. Crea `solucion/respuesta.txt` listando 5 atajos esenciales con su acción.
2. Incluye al menos: Quick Open, Toggle sidebar, Go to definition.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Ctrl+P: Quick Open (abrir archivo)
Ctrl+B: Mostrar/ocultar barra lateral
F12: Ir a definición
Ctrl+Shift+P: Paleta de comandos
Ctrl+D: Seleccionar siguiente ocurrencia
```
