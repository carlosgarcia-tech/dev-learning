# 02 — pnpm init

## Enunciado

Crea un proyecto con pnpm.

## Requisitos

1. En `solucion/`, ejecuta `pnpm init`.
2. Edita el `package.json` para que tenga `name: "mi-app"` y un script `start`.

## Pistas

- `pnpm init` genera un `package.json` igual que `npm init`.

## Solución

<details>
<summary>Mostrar solución</summary>

```bash
cd solucion
pnpm init
# editar package.json
```

</details>
