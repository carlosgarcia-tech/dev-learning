# 02 — settings.json de usuario

## Enunciado

Configura VS Code con `settings.json`.

## Requisitos

1. Crea `solucion/settings.json` con:
   - `editor.fontSize`: 14
   - `editor.tabSize`: 2
   - `editor.formatOnSave`: true
   - `files.autoSave`: "afterDelay"

## Solución

<details>
<summary>Mostrar solución</summary>

```json
{
  "editor.fontSize": 14,
  "editor.tabSize": 2,
  "editor.formatOnSave": true,
  "files.autoSave": "afterDelay"
}
```

</details>
