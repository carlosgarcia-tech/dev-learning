# CSS

> Guía de estudio + ejercicios por niveles para dominar CSS desde cero hasta nivel avanzado.

CSS (Cascading Style Sheets) es el lenguaje que define la apariencia, el layout y las animaciones de la web. Esta sección cubre desde los selectores y el box model hasta arquitecturas modernas, Sass y Tailwind.

## Guías de estudio

| # | Guía | Qué cubre |
|---|---|---|
| 01 | [Fundamentos](01-fundamentos.md) | Selectores, especificidad, cascada, herencia, box model, colores, unidades, tipografía |
| 02 | [Layout y Flexbox](02-layout-y-flexbox.md) | Display, position, float, flexbox, align, justify, wrap, order |
| 03 | [Grid y Responsive](03-grid-y-responsive.md) | CSS Grid, grid-template, áreas, responsive, media queries, mobile-first, container queries |
| 04 | [Animaciones y transiciones](04-animaciones-y-transiciones.md) | Transitions, transforms, animations, keyframes, cubic-bezier, will-change |
| 05 | [Arquitectura y producción](05-arquitectura-y-produccion.md) | BEM, SMACSS, ITCSS, CSS Modules, Tailwind, Sass/SCSS, PostCSS, variables CSS, theming, performance |
