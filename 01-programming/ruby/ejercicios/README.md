## Cómo trabajar cada ejercicio

1. Entra a la carpeta del ejercicio y lee su `README.md`.
2. Completa `main.rb` (reemplaza el `TODO`).
3. Corre los tests: `ruby test_main.rb`
4. Si te atoras, revisa las pistas y luego la solución en el `README.md`.

## Generar un ejercicio nuevo

Usa el script incluido en [`scripts/new-exercise-ruby.sh`](../../../../scripts/new-exercise-ruby.sh):

```bash
./scripts/new-exercise-ruby.sh nivel-01-fundamentos 01 hola-mundo
```
