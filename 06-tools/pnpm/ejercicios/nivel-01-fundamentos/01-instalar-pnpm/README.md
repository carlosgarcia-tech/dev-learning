# 01 — Instalar pnpm

## Enunciado

Instala pnpm y verifica su versión.

## Requisitos

1. Instala pnpm globalmente con `npm install -g pnpm` (o corepack).
2. Guarda la salida de `pnpm -v` en `solucion/version.txt`.

## Pistas

- También puedes usar `corepack enable`.

## Solución

<details>
<summary>Mostrar solución</summary>

```bash
npm install -g pnpm
pnpm -v > solucion/version.txt
```

</details>
