# 04 — Profiles

## Enunciado

Crea profiles para separar contextos.

## Requisitos

1. Explica en `respuesta.txt` cómo crear un profile desde la paleta de comandos.
2. Menciona un caso de uso.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Crear profile: paleta > Profiles: Create Profile > elegir nombre y qué incluir.
Caso de uso: un profile para Python (con sus extensiones y settings) y otro para frontend (con ESLint, Prettier, etc.).
```

</details>
