# 06 — Output JSON

## Enunciado

Obtiene salida estructurada de opencode.

## Requisitos

1. Explica en `respuesta.txt` cómo obtener salida JSON de opencode run.
2. Menciona para qué sirve `--output json`.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
opencode run "prompt" --output json
--output json devuelve el resultado en formato JSON, útil para parsear en scripts y CI.
```

</details>
