# 06 — pnpm-lock.yaml

## Enunciado

Analiza el lockfile de pnpm.

## Requisitos

1. En `solucion/`, verifica que existe `pnpm-lock.yaml`.
2. Explica en `respuesta.txt` qué información guarda el lockfile.

## Pistas

- Guarda versiones exactas, dependencias y la estructura del store.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
pnpm-lock.yaml guarda: la versión exacta de cada dependencia (directa y transitiva), los importers (qué pide cada paquete del workspace), y la estructura de paquetes con sus dependencias.
```

</details>
