# 03 — pnpm add

## Enunciado

Añade dependencias con pnpm.

## Requisitos

1. En `solucion/`, añade `express` con `pnpm add express`.
2. Añade `jest` como devDependency con `pnpm add -D jest`.

## Pistas

- `pnpm add` es el equivalente a `npm install`.

## Solución

<details>
<summary>Mostrar solución</summary>

```bash
cd solucion
pnpm add express
pnpm add -D jest
```

</details>
