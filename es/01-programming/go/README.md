# Go (Golang)

Go es un lenguaje de programación creado por Google, diseñado para ser simple, eficiente y seguro. Este curso cubre desde los fundamentos hasta conceptos avanzados de concurrencia y diseño de sistemas.

## Guías de estudio

1. [Fundamentos de Go](./01-fundamentos.md) - Variables, tipos, condicionales, bucles
2. [Funciones y Structs](./02-funciones-y-structs.md) - Funciones avanzadas, structs y métodos
3. [Interfaces](./03-interfaces.md) - Interfaces y polimorfismo
4. [Concurrencia](./04-concurrencia.md) - Goroutines, channels y select
5. [Errores y Testing](./05-errores-y-testing.md) - Manejo de errores y pruebas unitarias
