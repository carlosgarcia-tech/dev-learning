# SQL

> Complete study guide with four theory guides and 30 leveled exercises,
> from basic `SELECT` to a full mini-CRM project. All exercises work with
> SQLite and PostgreSQL.

| [04 — Transactions](04-transactions.md) | BEGIN, COMMIT, ROLLBACK, ACID, isolation levels |

## How to practice

1. Read the guide that matches the level you are studying.
2. Open the exercise file, read the statement, and create the initial schema.
3. Write your own query, then compare with the hidden solution.

You can run the examples with SQLite (`sqlite3`), or adapt them to PostgreSQL.
