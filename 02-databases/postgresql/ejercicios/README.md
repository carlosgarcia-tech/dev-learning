# Ejercicios — PostgreSQL

30 ejercicios organizados en 5 niveles de dificultad creciente, más un
proyecto final integrador.

- [Nivel 1 — Fundamentos](./nivel-01-fundamentos/)
- [Nivel 2 — Básico](./nivel-02-basico/)
- [Nivel 3 — Intermedio](./nivel-03-intermedio/)
- [Nivel 4 — Avanzado](./nivel-04-avanzado/)
- [Nivel 5 — Experto](./nivel-05-experto/)
- [Proyecto final](./proyectos/proyecto-final/)

Cada ejercicio trae `README.md` (enunciado + solución comentada),
`init.sql` (esquema de partida), `solucion.sql`, `checks.sql`
(verificación automática) y `test.sh` (los corre todos contra una base de
datos de pruebas desechable).
