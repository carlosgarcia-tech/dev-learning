# Ejercicios — TypeScript

30 ejercicios en 5 niveles de dificultad. Cada ejercicio tiene **enunciado, requisitos, pistas y solución** (plegable). Verifica cada solución con `npx tsc --strict <archivo>.ts` (los ejercicios de Node además requieren `@types/node`).
