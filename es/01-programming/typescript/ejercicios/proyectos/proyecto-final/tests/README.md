# Tests del Proyecto Final

Coloca aquí los tests de integración (`auth.test.ts`, `category.test.ts`,
`task.test.ts`) y crea `unit/` para los tests unitarios de servicios y
schemas, según la estructura descrita en el README principal del proyecto.

Ejecuta los tests compilados con:

```bash
npm run build
node --test dist/tests/**/*.test.js
```
