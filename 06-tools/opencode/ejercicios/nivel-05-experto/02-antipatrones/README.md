# 02 — Antipatrones

## Enunciado

Identifica antipatrones en el uso de opencode.

## Requisitos

1. Crea `solucion/respuesta.txt` con 3 antipatrones y cómo evitarlos.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
1. Confianza ciega: usar --yolo sin revisar. Evitar: siempre revisar diffs.
2. Prompts vagos: "arregla el código". Evitar: especificar archivos y comportamiento.
3. No verificar con tests: aceptar cambios sin probar. Evitar: ejecutar tests tras cambios.
```
