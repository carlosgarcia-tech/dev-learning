# Nivel 4 — Avanzado (MySQL)

Stored procedures, triggers, funciones de usuario, eventos, FULLTEXT y particionamiento.
Estos ejercicios usan características específicas de MySQL; `test.sh` las ejecuta en
MySQL real y, en el fallback de SQLite, valida la consulta equivalente portable.
