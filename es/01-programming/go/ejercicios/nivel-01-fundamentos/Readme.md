# Nivel 1: Fundamentos de Go

Este nivel cubre los conceptos básicos de Go, incluyendo variables, tipos, operadores, condicionales, bucles, funciones básicas, arrays y maps.

## Ejercicios

| # | Ejercicio | Descripción | Dificultad |
|---|-----------|-------------|------------|
| 01 | [Variables y tipos](./ejercicio-01-variables-y-tipos/) | Declaración de variables y tipos básicos | ⭐ |
| 02 | [Operadores y condicionales](./ejercicio-02-operadores-y-condicionales/) | Uso de operadores y estructuras if/else | ⭐⭐ |
| 03 | [Bucles](./ejercicio-03-bucles/) | Uso de bucles for en diferentes formas | ⭐⭐ |
| 04 | [Funciones básicas](./ejercicio-04-funciones-basicas/) | Declaración y uso de funciones | ⭐⭐ |
| 05 | [Arrays y slices](./ejercicio-05-arrays-y-slices/) | Trabajo con arrays y slices dinámicos | ⭐⭐ |
| 06 | [Maps](./ejercicio-06-maps/) | Uso de maps para almacenar pares clave-valor | ⭐⭐⭐ |

## Cómo ejecutar los ejercicios

1. Navega a la carpeta del ejercicio
2. Ejecuta: `go run main.go` para probar el programa
3. Ejecuta: `go test -v ./...` para ejecutar los tests

## Requisitos

- Go instalado (versión 1.21 o superior)
- Conocimientos básicos de programación
