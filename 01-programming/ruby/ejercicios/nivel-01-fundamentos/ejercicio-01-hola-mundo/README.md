# Ejercicio 01 — Hola Mundo

- **Nivel:** 1/5
- **Tema:** Fundamentos de Ruby
- **Tiempo estimado:** 10 minutos

## Enunciado

Crea un programa Ruby que:
1. Muestre "¡Hola, mundo!"
2. Muestre un saludo personalizado con tu nombre usando interpolación

## Requisitos

- [ ] El programa se ejecuta sin errores
- [ ] La lógica pedida en el enunciado está implementada
- [ ] Los tests pasan: `ruby test_main.rb`

## Pistas

<details>
<summary>Mostrar pistas</summary>

1. Usa `puts` para imprimir
2. Usa interpolación: `"Hola, #{nombre}"`
</details>

## Solución

<details>
<summary>Mostrar solución</summary>

```ruby
puts "¡Hola, mundo!"
nombre = "Ana"
puts "Mi nombre es #{nombre}"
```

</details>
