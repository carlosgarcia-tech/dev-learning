# 03 — .npmrc de pnpm

## Enunciado

Configura pnpm con `.npmrc`.

## Requisitos

1. Crea `solucion/.npmrc`.
2. Configura `auto-install-peers=true`.
3. Configura `shamefully-hoist=false`.

## Solución

<details>
<summary>Mostrar solución</summary>

```ini
# .npmrc
auto-install-peers=true
shamefully-hoist=false
```

</details>
