# JavaScript (Frontend)

> Guía de estudio + ejercicios por niveles para dominar JavaScript en el navegador.

JavaScript es el lenguaje que da interactividad a la web. Esta sección se centra en el JS del lado del cliente: manipulación del DOM, eventos, fetch, Web APIs, módulos y bundlers.

## Guías de estudio

| # | Guía | Qué cubre |
|---|---|---|
| 01 | [Fundamentos del DOM](01-fundamentos-dom.md) | DOM, selectores, manipulación del DOM, eventos, event delegation, bubbling, capturing |
| 02 | [Eventos y formularios](02-eventos-y-formularios.md) | Tipos de eventos, event object, preventDefault, stopPropagation, validación de formularios, FormData |
| 03 | [Fetch y async](03-fetch-y-async.md) | fetch API, promises, async/await, manejo de errores, interceptores, carga de datos, loading states |
| 04 | [Web APIs](04-web-apis.md) | localStorage, sessionStorage, IndexedDB, IntersectionObserver, MutationObserver, Web Workers, Service Workers, geolocation |
| 05 | [Módulos y bundlers](05-modulos-y-bundlers.md) | ES modules, import/export, dynamic import, bundlers (Webpack, Vite, esbuild), tree shaking, code splitting |
