# 06 — Lanzar opencode

## Enunciado

Lanza opencode en un proyecto.

## Requisitos

1. Explica en `respuesta.txt` desde qué directorio conviene lanzar opencode y por qué.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Conviene lanzar opencode desde la raíz del proyecto para que tenga acceso a todo el contexto (archivos, configs, git). opencode solo puede ver archivos dentro del directorio desde donde se lanza.
```

</details>
