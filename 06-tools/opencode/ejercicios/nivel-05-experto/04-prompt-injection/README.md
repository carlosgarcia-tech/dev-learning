# 04 — Prompt injection

## Enunciado

Entiende el riesgo de prompt injection.

## Requisitos

1. Explica en `respuesta.txt` qué es el prompt injection y cómo mitigarlo.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Prompt injection: input malicioso (ej: en un issue de GitHub o contenido web) que engaña al agente para que ejecute acciones no deseadas.
Mitigación: tratar los outputs como no confiables, no procesar datos externos sin revisión, y mantener permisos restrictivos.
```
