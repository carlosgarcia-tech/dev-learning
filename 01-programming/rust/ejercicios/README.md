# Ejercicios — Rust

30 ejercicios en 5 niveles de dificultad. Cada ejercicio es una carpeta con **enunciado, pistas y solución** (`README.md`), un **esqueleto** (`src/main.rs` con la firma y los tests) y su `Cargo.toml`. Implementa el esqueleto y verifica con `cargo test` dentro de la carpeta del ejercicio.
