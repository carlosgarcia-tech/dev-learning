# 03 — Dist-tags

## Enunciado

Aprende a publicar con un dist-tag distinto de `latest`.

## Requisitos

1. Explica en `respuesta.txt` para qué sirve `npm publish --tag beta`.
2. Menciona qué comando instalaría la versión beta.

## Pistas

- `--tag` asigna una etiqueta distinta a `latest`.
- Se instala con `npm install paquete@beta`.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
npm publish --tag beta publica la versión bajo la etiqueta "beta" en vez de "latest".
Se instala con: npm install paquete@beta
```

</details>
