# HTML

> Guía de estudio + ejercicios por niveles para dominar HTML desde cero hasta nivel avanzado.

HTML (HyperText Markup Language) es el lenguaje de marcado que da estructura y significado a todo el contenido de la web. Esta sección cubre desde la sintaxis básica de etiquetas hasta APIs modernas del navegador como Web Components y Service Workers.

## Guías de estudio

| # | Guía | Qué cubre |
|---|---|---|
| 01 | [Fundamentos](01-fundamentos.md) | Estructura HTML, etiquetas, atributos, texto, encabezados, párrafos, listas, enlaces, imágenes, tablas, formularios, HTML semántico, accesibilidad, SEO básico |
| 02 | [Formularios y multimedia](02-formularios-y-multimedia.md) | Input types, select, textarea, button, validación HTML5, audio, video, canvas, iframe, embed |
| 03 | [CSS aplicado](03-css-aplicado.md) | Estilos inline/internos/externos, selectores, box model, flexbox, grid, responsive design, media queries, animaciones |
| 04 | [Accesibilidad y SEO](04-accesibilidad-y-seo.md) | ARIA, roles, landmarks, alt text, semántica, meta tags, Open Graph, structured data, performance, Core Web Vitals |
| 05 | [HTML moderno y avanzado](05-html-moderno-y-avanzado.md) | Web Components, Custom Elements, Shadow DOM, templates, slots, web storage, geolocation, Intersection Observer, Service Workers, PWA |
