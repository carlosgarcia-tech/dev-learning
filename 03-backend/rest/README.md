| Guía | Qué cubre |

| [01 — Fundamentos](01-fundamentos.md) | Qué es REST, principios, recursos y URIs, métodos HTTP, representaciones, status codes, diseño de URLs |
| [02 — Diseño de API](02-diseno-de-api.md) | Modelado de recursos, naming, relaciones, sub-recursos, paginación, filtrado, versionado, content negotiation, HATEOAS |
| [03 — CRUD y Validación](03-crud-y-validacion.md) | CRUD completo, validación de entrada, manejo de errores, idempotencia, PATCH vs PUT, soft delete, timestamps |
| [04 — Seguridad y Paginación](04-seguridad-y-paginacion.md) | Autenticación, autorización, rate limiting, CORS, HTTPS, input sanitization, OWASP, paginación avanzada |
| [05 — Producción y Buenas Prácticas](05-produccion-y-buenas-practicas.md) | OpenAPI/Swagger, versionado, caching, idempotency keys, webhooks, bulk ops, async, API gateway, microservicios, testing |
