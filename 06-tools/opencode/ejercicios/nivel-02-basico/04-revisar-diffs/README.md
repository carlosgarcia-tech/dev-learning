# 04 — Revisar diffs

## Enunciado

Aprende a revisar los cambios propuestos.

## Requisitos

1. Explica en `respuesta.txt` por qué es importante revisar los diffs antes de aceptar.
2. Menciona qué buscar al revisar.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Es importante revisar los diffs porque el agente puede cometer errores o introducir bugs. Al revisar, buscar: cambios no esperados, seguridad (inyección, secretos), y que se respete el estilo del proyecto.
```
