# 06 — Logpoints

## Enunciado

Usa logpoints en lugar de console.log.

## Requisitos

1. Explica en `respuesta.txt` qué es un logpoint y cómo se diferencia de un breakpoint.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Un logpoint es un breakpoint que no pausa la ejecución, solo imprime un mensaje. Se pone click derecho en el margen > Add Logpoint. Útil para añadir logs sin tocar el código ni recompilar.
```

</details>
