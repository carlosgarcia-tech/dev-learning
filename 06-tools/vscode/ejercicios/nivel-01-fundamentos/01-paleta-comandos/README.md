# 01 — Paleta de comandos

## Enunciado

Aprende a usar la paleta de comandos.

## Requisitos

1. Explica en `solucion/respuesta.txt` cómo abrir la paleta de comandos en Windows/Linux y macOS.
2. Menciona la diferencia entre escribir `>` y no escribirlo.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Paleta de comandos: Ctrl+Shift+P (Win/Linux) o Cmd+Shift+P (macOS).
Con > al inicio: busca comandos.
Sin >: busca archivos (equivale a Ctrl+P).
```

</details>
