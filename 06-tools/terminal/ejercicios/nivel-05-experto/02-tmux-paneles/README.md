# 02 — Paneles de tmux

## Enunciado

Divide la pantalla en paneles.

## Requisitos

1. Explica en `respuesta.txt` cómo dividir vertical y horizontal.
2. Cómo mover el foco entre paneles.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Dividir vertical: Ctrl+B %
Dividir horizontal: Ctrl+B "
Mover foco: Ctrl+B + flechas
```

</details>
