# 01 — Instalar extensiones por CLI

## Enunciado

Instala extensiones desde la línea de comandos.

## Requisitos

1. Explica en `respuesta.txt` el comando para instalar la extensión de ESLint por CLI.
2. Menciona cómo listar las extensiones instaladas.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Instalar: code --install-extension dbaeumer.vscode-eslint
Listar: code --list-extensions
```

</details>
