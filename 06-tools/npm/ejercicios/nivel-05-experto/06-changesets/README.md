# 06 — Changesets

## Enunciado

Explica cómo usar changesets para gestionar versiones en un monorepo.

## Requisitos

1. Crea `solucion/respuesta.txt`.
2. Explica los tres pasos: `changeset`, `changeset version`, `changeset publish`.
3. Menciona qué genera automáticamente.

## Pistas

- Changesets calcula qué paquetes bump y genera CHANGELOGs.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Changesets gestiona versiones en monorepos:
1. npx changeset: registrar un cambio (tipo y descripción).
2. npx changeset version: bump versiones y generar CHANGELOG.md.
3. npx changeset publish: publicar al registry.
Genera automáticamente CHANGELOG.md y calcula qué paquetes subir de versión.
```

</details>
