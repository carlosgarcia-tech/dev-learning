# 01 — Multi-cursor

## Enunciado

Practica la edición con múltiples cursores.

## Requisitos

1. Explica en `respuesta.txt` 3 formas distintas de crear múltiples cursores.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
1. Alt+Click para añadir cursores.
2. Ctrl+D para seleccionar la siguiente ocurrencia.
3. Ctrl+Alt+Up/Down para añadir cursores en líneas verticales.
```

</details>
