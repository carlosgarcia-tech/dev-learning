# Ejercicio 06 — Strings

- **Nivel:** 1/5
- **Tema:** Fundamentos de Java
- **Tiempo estimado:** 20 minutos

## Enunciado

Dada una frase, escribe métodos que: cuenten el número de palabras, inviertan la frase, verifiquen si es un palíndromo (ignorando espacios y mayúsculas/minúsculas), y cuenten cuántas veces aparece una letra específica.

## Requisitos

- [ ] El programa compila sin errores (`javac Main.java`)
- [ ] El programa se ejecuta correctamente (`java Main`)
- [ ] La solución cubre todos los puntos del enunciado
- [ ] El código sigue las convenciones de Java (camelCase, indentación, nombres descriptivos)
- [ ] Los tests pasan: `java MainTest`

## Pistas

<details>
<summary>Mostrar pistas</summary>

1. `String.split(" ")` divide la frase en palabras.
2. `StringBuilder(texto).reverse()` invierte un String eficientemente.
3. Para un palíndromo, compara el texto normalizado con su versión invertida.

</details>
