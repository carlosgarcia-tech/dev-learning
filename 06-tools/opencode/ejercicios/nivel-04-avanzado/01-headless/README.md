# 01 — opencode run headless

## Enunciado

Ejecuta opencode en modo headless.

## Requisitos

1. Explica en `respuesta.txt` cómo ejecutar opencode en modo headless con un prompt.
2. Menciona la bandera `--auto`.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
opencode run "Añade un test para src/utils.js" --auto
--auto aprueba acciones automáticamente sin pedir confirmación.
```
