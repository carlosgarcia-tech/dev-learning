# 01 — Terminal integrada

## Enunciado

Aprende a usar la terminal integrada.

## Requisitos

1. Explica en `respuesta.txt` el atajo para abrir la terminal integrada.
2. Menciona cómo abrir una terminal externa.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Terminal integrada: Ctrl+` (backtick).
Terminal externa: Ctrl+Shift+` o paleta > Terminal: Create New External Terminal.
```

</details>
