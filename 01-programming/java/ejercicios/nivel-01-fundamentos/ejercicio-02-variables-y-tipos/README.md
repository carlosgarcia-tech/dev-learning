# Ejercicio 02 — Variables y Tipos

- **Nivel:** 1/5
- **Tema:** Fundamentos de Java
- **Tiempo estimado:** 15 minutos

## Enunciado

Declara al menos una variable de cada tipo primitivo (byte, short, int, long, float, double, char, boolean) y dos variables de tipo String. Imprime todas las variables junto con su tipo. Declara además una constante (`final`) con el valor de PI y úsala para calcular el área de un círculo de radio 5.

## Requisitos

- [ ] El programa compila sin errores (`javac Main.java`)
- [ ] El programa se ejecuta correctamente (`java Main`)
- [ ] La solución cubre todos los puntos del enunciado
- [ ] El código sigue las convenciones de Java (camelCase, indentación, nombres descriptivos)
- [ ] Los tests pasan: `java MainTest`

## Pistas

<details>
<summary>Mostrar pistas</summary>

1. Usa `final` para las constantes.
2. Recuerda el sufijo `f` para float y `L` para long.
3. `System.out.printf` es útil para mostrar el tipo junto al valor.

</details>
