# 01 — Navegación básica

## Enunciado

Practica la navegación por directorios.

## Requisitos

1. Crea `solucion/respuesta.txt` con los comandos para:
   - Ver el directorio actual.
   - Ir al directorio padre.
   - Ir al home.
   - Volver al directorio anterior.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
pwd
cd ..
cd ~
cd -
```

</details>
