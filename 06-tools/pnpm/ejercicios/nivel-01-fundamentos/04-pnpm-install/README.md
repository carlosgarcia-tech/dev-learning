# 04 — pnpm install

## Enunciado

Instala todas las dependencias declaradas.

## Requisitos

1. En `solucion/`, ejecuta `pnpm install`.
2. Verifica que existe `node_modules/` y `pnpm-lock.yaml`.

## Pistas

- `pnpm install` lee `package.json` y crea el lockfile.

## Solución

<details>
<summary>Mostrar solución</summary>

```bash
cd solucion
pnpm install
```

</details>
