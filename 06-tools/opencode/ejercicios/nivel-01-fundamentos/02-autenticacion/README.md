# 02 — Autenticación

## Enunciado

Autentica opencode con el proveedor.

## Requisitos

1. Explica en `respuesta.txt` cómo iniciar sesión con `opencode auth login`.
2. Menciona cómo verificar quién estás autenticado.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Iniciar sesión: opencode auth login (abre el flujo de autenticación).
Verificar: opencode auth status o opencode whoami.
```

</details>
