# 01 — Sesiones de tmux

## Enunciado

Crea y gestiona sesiones de tmux.

## Requisitos

1. Explica en `respuesta.txt` cómo crear una sesión tmux con nombre.
2. Cómo listar sesiones y cómo reconectarse (attach).
3. Cómo hacer detach.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Crear: tmux new -s trabajo
Listar: tmux ls
Reconectar: tmux attach -t trabajo
Detach: Ctrl+B D
```

</details>
