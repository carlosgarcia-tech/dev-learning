# 04 — nohup

## Enunciado

Ejecuta un proceso que sobreviva al cierre de terminal.

## Requisitos

1. Explica en `respuesta.txt` qué hace `nohup`.
2. Menciona dónde va la salida por defecto.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
nohup hace que un proceso sobreviva al cierre de la terminal (ignora SIGHUP).
La salida va a nohup.out por defecto, o se puede redirigir.
```

</details>
