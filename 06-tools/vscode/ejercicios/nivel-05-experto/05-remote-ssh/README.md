# 05 — Remote SSH

## Enunciado

Edita código en un servidor remoto.

## Requisitos

1. Explica en `respuesta.txt` cómo conectarte a un servidor por SSH con VS Code.
2. Menciona la extensión necesaria.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Instalar la extensión Remote - SSH.
Paleta > Remote-SSH: Connect to Host > introducir usuario@servidor.
VS Code se conecta y permite abrir carpetas del servidor, editar y debugar como si fuera local.
```

</details>
