# 05 — Dividir tareas grandes

## Enunciado

Aprende a dividir una feature grande en subtareas.

## Requisitos

1. Crea `solucion/tareas.txt` con 4 subtareas para implementar un módulo de pagos.

## Solución

<details>
<summary>Mostrar solución</summary>

`tareas.txt`:
```
1. Crear el modelo de datos en src/models/payment.js
2. Implementar el endpoint POST /api/payments en src/routes/payments.js
3. Añadir validación de campos en src/validators/payment.js
4. Escribir tests en tests/payments.test.js
```
