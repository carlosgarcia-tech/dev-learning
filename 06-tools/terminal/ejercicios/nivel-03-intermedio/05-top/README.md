# 05 — top/htop

## Enunciado

Monitoriza procesos en tiempo real.

## Requisitos

1. Explica en `respuesta.txt` qué información muestra `top`.
2. Menciona qué significa el load average.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
top muestra: uso de CPU, memoria, lista de procesos con su PID, usuario, %CPU, %MEM y comando.
Load average: carga media del sistema en los últimos 1, 5 y 15 minutos. Si es mayor que el número de CPUs, hay procesos esperando.
```

</details>
