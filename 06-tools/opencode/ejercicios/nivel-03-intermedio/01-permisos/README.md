# 01 — Configurar permisos

## Enunciado

Configura los permisos de opencode.

## Requisitos

1. En `solucion/opencode.json`, configura `permissions` con `edit: "ask"` y `bash: "ask"`.

## Solución

<details>
<summary>Mostrar solución</summary>

```json
{
  "permissions": {
    "edit": "ask",
    "bash": "ask"
  }
}
```

</details>
