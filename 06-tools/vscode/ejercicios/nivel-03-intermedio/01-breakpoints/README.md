# 01 — Breakpoints

## Enunciado

Aprende a poner breakpoints.

## Requisitos

1. Crea `solucion/app.js` con una función y un bucle.
2. Explica en `respuesta.txt` cómo poner un breakpoint condicional.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Click en el margen izquierdo para un breakpoint normal.
Click derecho > Add Conditional Breakpoint para uno condicional, y escribe una expresión como i === 5.
```

</details>
