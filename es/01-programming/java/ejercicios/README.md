# Ejercicios de Java — Índice

30 ejercicios progresivos (6 por nivel) + 1 proyecto final. Cada ejercicio contiene:

- `README.md` — enunciado, requisitos, pistas y solución
- `Main.java` — stub con `TODO`s para completar
- `MainTest.java` — suite de tests ejecutable con `java`

Para compilar y probar un ejercicio (desde su carpeta):

```bash
javac Main.java MainTest.java
java MainTest
```
