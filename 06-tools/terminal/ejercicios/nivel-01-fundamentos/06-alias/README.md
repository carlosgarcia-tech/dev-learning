# 06 — Alias

## Enunciado

Crea alias útiles.

## Requisitos

1. Crea `solucion/bashrc-extra.sh` con al menos 3 alias útiles (ll, gs, ..).

## Solución

<details>
<summary>Mostrar solución</summary>

```bash
# bashrc-extra.sh
alias ll='ls -lah'
alias gs='git status'
alias ..='cd ..'
```

</details>
