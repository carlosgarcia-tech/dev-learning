# 05 — Variables de entorno

## Enunciado

Configura opencode con variables de entorno.

## Requisitos

1. Explica en `respuesta.txt` qué variable de entorno se usa para la API key.
2. Menciona cómo fijar el modelo por entorno.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
API key: OPENCODE_API_KEY=sk-...
Fijar modelo: OPENCODE_MODEL=anthropic/claude-sonnet-4
```
