# 01 — Prompt efectivo

## Enunciado

Escribe un prompt efectivo para opencode.

## Requisitos

1. Crea `solucion/prompt.txt` con un prompt para añadir un endpoint GET /api/users.
2. El prompt debe especificar: archivo, comportamiento, y que añada tests.

## Solución

<details>
<summary>Mostrar solución</summary>

`prompt.txt`:
```
Añade un endpoint GET /api/users en src/routes/users.js que devuelva la lista de usuarios desde la base de datos. Usa el patrón existente del archivo. Añade tests en tests/users.test.js cubriendo el caso normal y el caso de lista vacía.
```
