# Ejercicio 04 — Bucles

- **Nivel:** 1/5
- **Tema:** Fundamentos de Java
- **Tiempo estimado:** 20 minutos

## Enunciado

Implementa un método que imprima la tabla de multiplicar del 1 al 10 para un número dado usando un bucle `for`. Implementa otro método que sume los números del 1 al 100 usando `while`. Usa `break`/`continue` en un tercer método que imprima solo los números impares entre 1 y 50, deteniéndose si encuentra un múltiplo de 33.

## Requisitos

- [ ] El programa compila sin errores (`javac Main.java`)
- [ ] El programa se ejecuta correctamente (`java Main`)
- [ ] La solución cubre todos los puntos del enunciado
- [ ] El código sigue las convenciones de Java (camelCase, indentación, nombres descriptivos)
- [ ] Los tests pasan: `java MainTest`

## Pistas

<details>
<summary>Mostrar pistas</summary>

1. `for (int i = 1; i <= 10; i++)` es el patrón clásico para tablas de multiplicar.
2. `continue` salta a la siguiente iteración; `break` termina el bucle.
3. Verifica los casos límite de tus condiciones de parada.

</details>
