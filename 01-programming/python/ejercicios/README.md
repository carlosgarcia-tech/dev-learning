# Ejercicios de Python — Índice

30 ejercicios progresivos (6 por nivel) + 3 proyectos integradores + 1 proyecto final. Cada ejercicio contiene:

- `README.md` — enunciado, requisitos, pistas y solución
- `main.py` — stub con `TODO`s y `raise NotImplementedError` para completar
- `test_main.py` — runner de tests con `unittest` (stdlib) y código de salida `0`/`1`

## Cómo ejecutar los tests

Desde la carpeta del ejercicio:

```bash
python3 test_main.py
```

> Los tests usan **`unittest`** de la biblioteca estándar: no requieren instalar
> ninguna dependencia. Todos los runners se verificaron con la solución documentada
> en cada `README.md` (`python3 test_main.py` devuelve `0`).

El runner imprime `Ran N tests` + `OK` y termina con código de salida `0` (todo pasa) o `1` (hay fallos).
