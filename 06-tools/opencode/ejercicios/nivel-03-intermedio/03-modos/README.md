# 03 — Modos de operación

## Enunciado

Comprende los modos ask, auto y yolo.

## Requisitos

1. Crea `solucion/respuesta.txt` explicando los 3 modos de permiso y cuándo usar cada uno.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
ask: pregunta antes de cada acción. Recomendado para uso normal.
auto: acepta acciones seguras automáticamente. Para tareas repetitivas de confianza.
yolo: acepta todo sin preguntar. Solo en entornos desechables (contenedores, sandboxes).
```
