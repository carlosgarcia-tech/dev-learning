# Ejercicios de JavaScript — Índice

30 ejercicios progresivos (6 por nivel) + 3 proyectos integradores + 1 proyecto final. Cada ejercicio contiene:

- `README.md` — enunciado, requisitos, pistas y solución
- `index.js` — stub con `TODO`s y `throw new Error` para completar
- `index.test.js` — tests con el módulo `node:test`

## Cómo ejecutar los tests

Desde la carpeta del ejercicio:

```bash
node --test index.test.js
```

> Los tests usan `node:test` y `node:assert/strict` de la biblioteca estándar de
> Node.js: no requieren instalar dependencias. Ejecuta `node index.js` para
> probar la solución.

## Cómo ejecutar

- **Programa:** ejecuta `node index.js` dentro de la carpeta del ejercicio.
- **Tests:** ejecuta `node --test index.test.js` dentro de la carpeta del ejercicio.
- **Servidores HTTP:** `node index.js` en una terminal y prueba con `curl` desde otra.
- **Crear ejercicios nuevos:** usa `scripts/new-exercise-javascript.sh`.
