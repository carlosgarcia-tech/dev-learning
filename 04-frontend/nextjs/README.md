# Next.js

> Guía de estudio + ejercicios por niveles para dominar Next.js.

Next.js es el framework de React más popular. Añade routing basado en archivos, renderizado en servidor (SSR/SSG/ISR), Server Components y optimizaciones integradas.

## Guías de estudio

| # | Guía | Qué cubre |
|---|---|---|
| 01 | [Fundamentos](01-fundamentos.md) | Qué es Next.js, App Router, file-based routing, layout, page, loading, error, route handlers |
| 02 | [Rutas y data fetching](02-rutas-y-data-fetching.md) | Rutas dinámicas, generateStaticParams, Server Components, Client Components, fetch, cache, revalidate |
| 03 | [SSR, SSG e ISR](03-ssr-ssg-isr.md) | getServerSideProps (Pages Router), SSR, SSG, ISR, App Router data fetching, streaming |
| 04 | [API routes y middleware](04-api-routes-y-middleware.md) | Route Handlers, API routes, middleware, cookies, headers, redirects, rewrites |
| 05 | [Producción y deploy](05-produccion-y-deploy.md) | Optimización de imágenes, fonts, metadata, SEO, Vercel deploy, Docker, middlewares, i18n |
