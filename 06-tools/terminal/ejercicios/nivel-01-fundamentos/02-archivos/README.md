# 02 — Crear y borrar archivos

## Enunciado

Practica la creación y borrado de archivos.

## Requisitos

1. En `solucion/`, crea un archivo `notas.txt` con `touch`.
2. Crea un directorio `backups/` con `mkdir`.
3. Crea `a/b/c/` con `mkdir -p`.

## Solución

<details>
<summary>Mostrar solución</summary>

```bash
cd solucion
touch notas.txt
mkdir backups
mkdir -p a/b/c
```

</details>
