# 04 — Git stage y commit

## Enunciado

Practica el flujo de git desde VS Code.

## Requisitos

1. Explica en `respuesta.txt` cómo hacer stage de un archivo desde la UI.
2. Explica cómo hacer commit desde la UI.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
Stage: en la vista Source Control (Ctrl+Shift+G), click en + junto al archivo.
Commit: escribe el mensaje en el cuadro y pulsa Ctrl+Enter.
```
