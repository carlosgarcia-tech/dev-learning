# 04 — Watch

## Enunciado

Usa la sección Watch para monitorizar expresiones.

## Requisitos

1. Explica en `respuesta.txt` cómo añadir una expresión al Watch.
2. Menciona un caso de uso.

## Solución

<details>
<summary>Mostrar solución</summary>

`respuesta.txt`:
```
En la sección Watch del panel de debug, click en + y escribe la expresión (ej: users.length o total > 100).
Caso de uso: seguir el valor de una variable a lo largo de la ejecución sin añadir console.log.
```

</details>
